# 🎮 Space Game using Java AWT

## 📌 Project Description

This project is a simple 2D bouncing ball game developed using **Java AWT (Abstract Window Toolkit)**.
The player controls a paddle to bounce a moving ball. Each successful bounce increases the score.

---

## 🚀 Features

* Ball moves continuously on the screen
* Paddle controlled by keyboard (Left/Right arrows)
* Collision detection with walls and paddle
* Score increases on each successful bounce
* Score resets when the ball is missed

---

## 🛠️ Technologies Used

* Java
* AWT (Abstract Window Toolkit)
* Event Handling (KeyListener)
* Multithreading (Thread class)

---

## 🎮 How to Play

* Use **Left Arrow (⬅️)** to move paddle left
* Use **Right Arrow (➡️)** to move paddle right
* Try to keep the ball bouncing using the paddle
* Each successful hit increases your score
* Missing the ball resets the score

---

## ▶️ How to Run the Project

1. Open terminal in the project folder
2. Compile the program:

   ```bash
   javac BounceGame.java
   ```
3. Run the program:

   ```bash
   java BounceGame
   ```
